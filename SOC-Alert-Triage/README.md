# SOC Alert Triage & Investigation — TryHackMe SOC Simulator

## Overview

Hands-on SOC alert triage and phishing investigation project completed in the TryHackMe SOC Simulator, a simulated Security Operations Center environment.

The project focuses on security alert analysis, true/false positive identification, phishing investigation, incident assessment, and evidence-based SOC case documentation.

## Objectives

- Monitor and analyze security alerts
- Triage alerts and determine their severity
- Identify true-positive and benign alerts
- Investigate phishing-related activity
- Analyze suspicious PowerShell, reverse-shell, and DNS activity
- Apply SOC investigation and escalation concepts
- Document findings in a structured incident report

## Investigation Workflow

**Monitor → Triage → Correlate → Investigate → Document → Assess**
